# 🛒 SQLite Sales Summary with Python

This project demonstrates how to analyze a small sales dataset stored in an SQLite database using Python. It includes data aggregation, SQL queries, and visualizations using pandas and matplotlib.

## 📂 Features

- Create and populate a `sales_data.db` database
- Run SQL queries from Python using `sqlite3`
- Display total revenue and quantity sold by product
- Generate:
  - 📊 Bar chart: Revenue by Product
  - 📈 Line chart: Daily Revenue
  - 🥧 Pie chart: Revenue Share by Category
- Export results to CSV files

## 📦 Requirements

- Python 3.x
- pandas
- matplotlib

## 🚀 How to Run

1. Clone this repo
2. Run the notebook: `sqlite3_analysis.ipynb`  
   OR run the `.py` script if provided
3. View printed outputs and generated charts
